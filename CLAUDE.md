# Старт разработки в оболочке GLM / Claude Code

Обязательные правила — в [AGENTS.md](AGENTS.md). Продолжение разработки — [docs/handoff-glm.md](docs/handoff-glm.md), готовое стартовое задание — [docs/start-glm.md](docs/start-glm.md).

Прочитайте их до изменений. Модель, endpoint, ключи и штатный механизм субагентов выбираются в вашей оболочке; этот файл не меняет настройки пользователя.

Канонические роли — `.agents/roles/*.md`. Если независимые контексты недоступны, сообщите об этом и используйте отдельную сессию для ревью. Самопроверку не выдавать за независимое ревью.
